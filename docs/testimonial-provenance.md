# Testimonial excerpt provenance

The site owner supplied screenshots of comments for use in the academy website revision. The source files were read locally; screenshots, profile pictures, reaction totals, and surrounding comments are not published or committed. This document records the provenance of the selected text in `apps/web/lib/testimonials.ts`.

These are excerpts of course feedback. They are not verified ratings, outcome guarantees, or testimonials about the current ACT programme. No star rating, reviewer occupation, enrolment record, programme completion status, or review date is inferred. The date in each filename identifies the supplied file and is not treated as the comment's date.

Arabic retains the readable source wording and spelling. Screenshot line wraps are removed. Only punctuation and spaces around punctuation are normalized for display. English and French are faithful translations of the selected excerpts and must display the translation label supplied by `testimonialCopy`.
