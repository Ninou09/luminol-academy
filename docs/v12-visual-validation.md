# V12 visual validation

V12 is the final corrective visual layer for the public Luminol experience.

The refinement keeps authentic Luminol Academy photography primary while adding resilient editorial fallbacks, tighter vertical rhythm, a denser image-led archive, clearer school pathways, a richer teal-aqua-gold palette, and progressive motion that never gates content visibility.

The final stylesheet is loaded after the earlier visual layers so the corrective rules remain deterministic without rewriting historical milestone styles.

Validation targets:

- authentic academy media remains visible without requiring animation state
- reveal effects fail open instead of leaving blank sections
- Arabic, French, and English public routes retain their existing content and navigation
- reduced-motion users receive a stable non-animated experience
- production security, formatting, type checking, tests, build, and public smoke checks remain green
