## قواعد كتابة التوثيق

- تُكتب النسخ العربية بالعربية الفصحى المعاصرة، بجمل واضحة وبصيغة المبني للمعلوم.
- تبقى المعرّفات والأوامر والمسارات وأسماء متغيّرات البيئة بالإنجليزية وبتنسيق `code` في اللغتين.
- عند تعديل دليل له نسخة عربية، حدّث النسختين في طلب الدمج نفسه.
- لا تتضمّن الوثائق أو لقطات الشاشة أي أسرار أو بيانات عملاء أو معلومات شخصية عن المتعلّمين.
