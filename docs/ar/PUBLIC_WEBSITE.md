# الموقع العام

[English](../PUBLIC_WEBSITE.md) · **العربية**

يمثّل `apps/web` الواجهة العامة للأكاديمية. يعرض المدارس الثلاث، ويحوّل الاهتمام إلى طلبات استشارة وبرامج، ويبني الثقة عبر محتوى واضح وهادئ ومترجَم بالكامل. يشرح هذا الدليل محتوى الموقع، وسلوك ميزاته الرئيسية، والقواعد التي يجب أن يحترمها كل تغيير.

## المسارات

يتوفّر كل مسار بالعربية والفرنسية والإنجليزية تحت `/ar` و`/fr` و`/en`.

| المسار                        | المحتوى                                                                                           |
| ----------------------------- | ------------------------------------------------------------------------------------------------- |
| `/`                           | الصفحة الرئيسية: المدارس الثلاث، والبرامج المميّزة، والفعاليات القادمة، والفريق، والنشرة البريدية |
| `/schools`                    | صفحة المدارس مع اختبار قصير يقترح المدرسة المناسبة                                                |
| `/schools/[school]`           | صفحات مدارس علم النفس واللغات والتطوير المهني                                                     |
| `/programmes`                 | فهرس البرامج مع البحث ومرشّحات محفوظة في الرابط                                                   |
| `/programmes/[slug]`          | تفاصيل البرنامج مع حالة التسجيل وطلب خاص بالبرنامج                                                |
| `/consultations`              | الاستشارات النفسية ونموذج طلب الاستشارة                                                           |
| `/approach`                   | المقاربة العلاجية والتعليمية للأكاديمية، ومنها نموذج ACT                                          |
| `/events`                     | أرشيف اللقاءات السابقة مرتّبة حسب تاريخ انتهائها بتوقيت الجزائر                                   |
| `/workshops/[slug]`           | صفحات المشاركين في ورشات العمل مع الجدول والأسئلة الشائعة وتنزيل التقويم                          |
| `/journal` و`/journal/[slug]` | المقالات التحريرية، وتُستبعد المسوّدات من فهرسة محرّكات البحث                                     |
| `/about` و`/contact`          | قصة الأكاديمية والفريق والعنوان وأوقات العمل وقنوات التواصل                                       |
| `/certificates/[id]`          | التحقق العلني من الشهادات دون كشف السجلّات غير المعروفة                                           |

الواجهات البرمجية: `/api/enquiries` و`/api/newsletter` و`/api/assistant` و`/api/events/[id]/calendar` (تنزيل iCalendar) و`/api/social-preview` (صور Open Graph) و`/api/webhooks/clerk`.

## الميزات

### الطلبات

تشترك نماذج الاستشارة والبرامج والتواصل في مسار طلبات واحد (راجع [البنية المعمارية](ARCHITECTURE.md)). يختار الزائر واتساب أو الهاتف أو البريد الإلكتروني. يتذكّر النموذج بيانات التواصل المُدخلة أثناء تبديل القناة، ولا يرسل إلا القناة المختارة، ويُبقي الحقول الاختيارية مطويّة، ويشترط الموافقة، ويحتفظ بالمدخلات بعد أي إخفاق ليتمكّن الزائر من إعادة المحاولة. تؤكّد الأكاديمية كل موعد بالتواصل مع الزائر، ولا يَعِد الموقع أبدًا بموعد محجوز.

### المساعد الذكي

مساعد عائم يجيب عن أسئلة المدارس والبرامج والاستشارات وأوقات العمل وقنوات التواصل. يطلب الموافقة قبل الرسالة الأولى، ويمتنع عن التشخيص أو اقتراح العلاج، ويجيب عن رسائل الأزمات ببيانات الطوارئ والتواصل البشري دون استدعاء النموذج. يُفعَّل عبر `ANTHROPIC_API_KEY`، ومن دونه يعرض قنوات تواصل الأكاديمية. راجع [الإعداد والنشر](CONFIGURATION.md).

### البحث

يربط بحث البرامج الكلمات اليومية بالإنجليزية والفرنسية والعربية والدارجة الجزائرية بالمواضيع والمدرسة التي تعنيها عادةً. فالزائر الذي يكتب «طفلي لا يسمع الكلام» أو «قلق» يجد البرامج المناسبة حتى لو لم ترد هذه الكلمات حرفيًا في العناوين.

### الفعاليات والتقويم

تظهر الفعاليات القادمة في الصفحة الرئيسية، وتنتقل الفعاليات السابقة إلى `/events`. تتيح كل فعالية تنزيل ملف `.ics` بتوقيت الجزائر يُفتح في أي تطبيق تقويم.

### إمكانية الوصول والراحة

- تتيح قائمة إعدادات العرض تكبير النص والتباين العالي، ويُحفظ الاختيار في المتصفح.
- يستبدل الوضع الهادئ الخلفية المتحرّكة بمنظر طبيعي ثابت.
- تتوقّف الحركة والفيديو والمشاهد ثلاثية الأبعاد عندما يطلب نظام الزائر تقليل الحركة.
- تحتوي كل صفحة على رابط تخطٍّ، ومناطق دلالية، وحالات تركيز ظاهرة، وأهداف لمس لا تقلّ عن 32 بكسل على الهاتف.
- تُفحص التخطيطات بعرض من 320 إلى 1920 بكسل دون تمرير أفقي أو نص مقصوص.

### رابط بوابة المتعلّمين

يعرض الشريط العلوي رابط **حسابي** إلى بوابة المتعلّمين بلغة الصفحة الحالية، ويأتي عنوانه من `NEXT_PUBLIC_PORTAL_URL`.

## قواعد التوطين

- العربية تُكتب من اليمين إلى اليسار. يضبط التخطيط الجذري `lang` و`dir` على المستند، وتستخدم المكوّنات خصائص CSS المنطقية (`inline-start` و`inline-end`) لتنعكس التخطيطات بشكل صحيح.
- يستخدم النص العربي خط Noto Sans Arabic دون تباعد الحروف اللاتيني، ويستخدم النص اللاتيني خطَّي Manrope وCormorant Garamond.
- يتوفّر كل نص ظاهر ونص بديل للصور وحقل بيانات وصفية باللغات الثلاث. وتُنشر لكل صفحة روابط معتمدة وبدائل `hreflang` وبديل `x-default`.
- تحقّق في المتصفح من أرقام الهواتف والأسعار والتواريخ داخل الجمل العربية: يجب أن تحافظ أرقامها على ترتيبها من اليسار إلى اليمين.

## قواعد الصور

- تستخدم كل صفحة صورها الخاصة، ولا تتكرّر الصورة نفسها في صفحة أخرى.
- كل صورة بصيغة WebP بأبعاد صريحة، ونص بديل باللغات الثلاث، ونيّة قصّ تُبقي الوجوه والعناصر الأساسية داخل الإطار.
- لا تُختلق صور لتمثيل أشخاص حقيقيين أو عملاء أو فعاليات. ولا تُنشر صور مؤقتة أو غير مراجَعة.
- تُسجَّل الأعمال الفنية المكلَّف بها وحقوق الصور في [وسائط الموقع العام](../cinematic-media.md) (بالإنجليزية).
